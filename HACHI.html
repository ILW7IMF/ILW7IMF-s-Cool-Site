Sonic 1 Hachi Framework

Sonic 1 Hachi Framework (S1HF) is a Sonic 1 ROM-hacking framework designed to make hacking easier by adding more complex functions that are commonly needed, along with various miscellaneous improvements. It is built separately from the base Sonic 1 disassembly, allowing experimentation and new features to be added without modifying the original project.

features

Hachi includes a variety of new functions and improvements, including:

- New Game Functions
- Extended title cards
- Per-act assets
- Flamewing's Ultra DMA Queue
- Spindash
- Clownacy's Sonic 2 Clone Driver v2
- Sub-sprites

Miscellaneous Improvements

Small layout fixes, such as fixing the oddly placed wall object near the beginning of Green Hill Zone Act 1
